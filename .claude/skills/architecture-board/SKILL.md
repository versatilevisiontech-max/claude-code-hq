# Architecture board

Each study has only:

- Name
- Type (house, atelier, pavilion, interior). Mark it as a study if it is not a built commission.
- One sentence on light, structure, or use
- Three facts: place type, material palette, what the plan protects

Do not invent dimensions, costs, consultants, or photographs. Describe a drawing if there is no photo.
