# Brand voice

- Studio name: Versatile Vision Tech.
- Short sentences. No exclamation marks.
- Do not use: elevate, unlock, seamless, cutting-edge, nestled, robust.
- Lead with what is seen: light, cloth, room, proportion.
- One idea per line.
- Hashtags only when asked, and never more than five.
- Instagram has two accounts. Ask which one if the user did not say.
