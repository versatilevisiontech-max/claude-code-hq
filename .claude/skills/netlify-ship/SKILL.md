# Netlify ship

1. `index.html` must open with no missing local files.
2. `netlify.toml` publish directory must match those files.
3. Do not add a framework, `package.json`, or secrets.
4. Do not deploy. Tell the user: Netlify → Add site → Import from Git → this repo → publish directory `.`
5. After they say it is live, check the contact email is versatilevisiontech@gmail.com.
