Open this repo in Claude Code once. Copy the rules into your home folder. Every other Versatile Vision repo then behaves the same way.

## Use in under 10 minutes

1. Install [Claude Code](https://github.com/anthropics/claude-code) (Claude Pro — already on the free stack).
2. Clone this repo and open it in Claude Code.
3. Copy `CLAUDE.md` to `~/.claude/CLAUDE.md`.
4. Copy the `.claude/skills` folder to `~/.claude/skills`.
5. Install the five upstream repos in [INSTALL.md](INSTALL.md). Do not fork them.
